# Isha's Developer Portfolio

A premium, futuristic developer portfolio showcasing my skills, projects, and experience as a web developer and UI/UX designer.

🔗 **Live Site:** [View Portfolio](https://ishaali.github.io/Isha-Portfolio) *(update with your GitHub Pages URL)*

---

## ✨ Features

- **Dark futuristic design** — Deep navy/black base with electric blue neon accents and cyan highlights
- **Glassmorphism UI** — Frosted glass cards, panels, and navbar
- **Smooth animations** — Scroll reveal, floating tech pills, profile ring glow, and micro-interactions
- **Interactive tabs** — Skills, Experience, and Education sections with animated progress bars
- **Project showcase** — Simon Game and BnB Management System with tech badge tags
- **Dark / Light mode** — Toggle with `localStorage` persistence
- **Responsive design** — Fully optimised for all screen sizes (320px → 1920px)
- **Preloader** — Animated progress bar on page load
- **Contact form** — Styled glass-effect form with social links

---

## 🛠️ Tech Stack

| Technology | Role |
